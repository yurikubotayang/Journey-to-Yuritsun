# Journey to Yuritsun

彼氏に贈る、遠距離期間を毎日1歩ずつ一緒に歩む再会カウントダウンゲーム。

1日1問クイズに答えると、その日の写真とメッセージが解放され、再会日への道が1歩進みます。不正解でも何度でも再挑戦できます。サーバー不要・ビルド不要の静的サイトです。

## カスタマイズ方法

`data.js` を編集してください。

- `START_DATE` / `REUNION_DATE`: ゲーム開始日と再会日（`YYYY-MM-DD`）
- `QUIZZES`: クイズ一覧。`choices` を書くと選択式、書かなければ自由記述式になります
- `MESSAGES`: 正解時に表示されるメッセージ一覧
- `PHOTOS`: `photos/` フォルダに入れた画像ファイル名の一覧

クイズ・メッセージ・写真は日数分より少なくても、繰り返し使い回されるので大丈夫です。写真は未設定でもハートのプレースホルダーが表示されるので、後から追加できます。

## ローカルで確認する

```
python3 -m http.server 8000
```

を実行して `http://localhost:8000` を開いてください。

## GitHub Pages で公開する

1. GitHubのリポジトリ設定 → Pages → Source を `main` ブランチ（ルート）に設定
2. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能になります
3. そのURLを彼に送ってください

進捗はブラウザの localStorage に保存されるため、同じ端末・同じブラウザで毎日開く必要があります。
